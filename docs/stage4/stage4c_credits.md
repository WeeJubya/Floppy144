# Stage 4C and BF33: Credits, Studio Mark and Runtime Provenance

BF33 replaces the old Credits' on-screen designer and GPL exposition with the original Grey Door Republik architectural studio logo, rendered procedurally in both Credits and the secret Developer office. The visible footer remains the same, including Enter to replay the introduction and Backspace to return to Settings or Completion.

Visible content: the game title, the studio symbol/wordmark, **(C) MMXXVI**, and the existing navigation. No `RUNTIME ACKNOWLEDGEMENT`, `GAME DESIGN COMPANY` or `MAIN DESIGNER / DEVELOPER` tag is shown.
